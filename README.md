# CirclePlay

CirclePlay est une application web statique : aucun serveur Node.js ni installation
de dépendances n'est nécessaire.

## Lancer l'application

Ouvrez `index.html` à la racine du projet dans un navigateur.

Les styles, scripts, jeux et images sont rangés dans `style.css`, `script.js`,
`Game/` et `img/`.
